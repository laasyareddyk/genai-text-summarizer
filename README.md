# GenAI Text Summarizer

## Overview

This project is a Generative AI application that uses Google's Gemini model to process user-provided text and generate a shorter, more concise version while preserving the important information.

The application allows users to enter or provide text and receive an AI-generated summary.

## Features

- Accepts user-provided text
- Uses Generative AI to understand the text
- Generates a concise summary
- Preserves important information
- Simple and user-friendly interface
- Interactive web application using Streamlit

## Technologies Used

- Python
- Google Gemini API
- Generative AI
- Streamlit

## How It Works

1. The user enters text into the application.
2. The text is sent to the Gemini Generative AI model.
3. The model analyzes the content.
4. The model generates a shorter and meaningful version of the text.
5. The generated output is displayed to the user.
